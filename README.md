# Notak

Notak (Notak Study Hub) is an immersive, distraction-free study sanctuary for varsity students. It's an offline-first note-taking app designed for collecting notes and organizing study folders.

## Features
- Immersive dashboard with real-time clock.
- Persistent "Crop & Center" background image system.
- Integrated smart music player with loop/shuffle functionality and bug-free state management.
- Cohesive, aesthetic UI with frost-glass styling.
- Smart file name display on vault cards.
- **Ocean Journey Animation:** Dynamic, physics-driven canvas animation acting as the Music Hub backdrop, featuring procedural multi-type islands (including tribal villages), reactive wave physics, and a realistically accelerating/decelerating Pirate Ship based on music playback state.
- **Full Mobile Responsiveness:** A comprehensive 360-degree CSS media query system that intelligently restacks the dashboard grids, Vault interface, Music Hub layout (including Zen Mode), and Calendar for a native-feeling experience on Android and smaller screens.

## How to run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python main.py
   ```
   Or use the provided script:
   ```bash
   ./run.sh
   ```
